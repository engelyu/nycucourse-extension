# 選課規劃頁：找空堂課程

日期：2026-09-19
狀態：設計已確認，待實作

## 目的

選課時想找「某些時段有什麼課可以上」。使用者自己框選時段、設定篩選條件，從全校課程資料找出落在這些時段的課，並可直接加入預排。

其他人做的同類工具，每個時段都要一格一格點，很難用。這裡的重點是**框選**，以及**一鍵帶入空堂**。

## 範圍

要做：

- 新增完整頁面「選課規劃」（新的 Chrome 分頁），找空堂是它的第一個功能。popup 右上加入口「規劃 ↗」。
- 時段格子：一到日 × Y–D 全 16 節，可以框選。
- 「帶入空堂」兩個按鈕，依據分開：避開正式選課；避開正式選課＋預排。兩種都避開自訂行程。
- 篩選：比對方式、校區、課程類別、開課單位、學分、關鍵字、排除已有的課。
- 結果清單：滑過在格子上預覽時段，可直接加入預排（含採計方式選擇）。
- 抓課程資料時多存類別代碼（用於課程類別篩選）。
- 記住選取的時段與篩選條件。

不做：

- 一鍵自動找課。篩選條件多，由使用者自己設定。
- 用選課網資料搜尋（要登入、全校約 300 個選單、約 5 分鐘）。
- 即時選課人數篩選（課程時間表沒有）。
- 選課規劃頁的整體 UI 設計。之後會整頁重做，這次先做到好用。

## 使用者確認過的決定

| 項目 | 決定 |
|---|---|
| 位置 | 新開「選課規劃」頁（完整分頁），找空堂是第一個功能 |
| 格子範圍 | 一到日 × Y–D 全部 16 節 |
| 帶入空堂 | 選進所有空格（含早晚、週末）；「避開正式選課」與「避開正式選課＋預排」分成兩個按鈕，都避開自訂行程 |

## 1. 資料與比對邏輯（純函式，`src/lib/`）

### 時段

一個時段用字串 `"<星期>-<節次代碼>"` 表示，星期 1–7（週一 = 1），節次代碼沿用 `PERIODS`（`y`、`z`、`1`…`9`、`n`、`a`…`d`）。例如 `"5-3"` 是週五第 3 節。選取範圍是時段的集合。全部時段共 7 × 16 = 112 個。

### 每門課的時段與校區

- 用 `parseCosTime(course.time)` 解析，得到 `[{ day, period, room, campus }]`。例如 `F345-EC115[GF]` 是週五 3、4、5 節，校區 GF。
- 校區代碼對照：GF 光復、YM 陽明、BA 博愛、LJ 六家、GR 歸仁、BM 北門、KS 高雄。未知代碼照原樣顯示。（2026-09-19 選課網資料：GF 1554 門、YM 999、BA 60、LJ 50、BM 49、GR 39、KS 21；17 門課跨兩個校區。）

### 比對方式

設課程時段集合為 C、選取範圍為 S：

- **完全落在內**：C 不是空的，而且 C 的每個時段都在 S 裡。
- **部分重疊**：C 和 S 至少有一個共同時段。結果標出「超出」的時段（C − S），例如「超出：五 5」。
- 完全落在內的課，在部分重疊模式下也會列出，歸在「完全落在內」那一組。
- 沒有上課時間的課（C 是空的，全校約 221 門）永遠不列。

### 帶入空堂

- 佔用時段 = `scheduleItems(schedule, 來源)` 所有項目的時段聯集。「避開正式選課」的來源是 `['registered']`；「避開正式選課＋預排」是 `['registered', 'preregist']`。`scheduleItems` 本來就會包含自訂行程並套用覆寫（被隱藏的課不算佔用）。
- 空堂 = 全部 112 個時段 − 佔用時段。
- 帶入會**取代**目前的選取。

### 課程類別

- 必修、選修：課程時間表的 `cos_type` 欄位（爬蟲存成 `type`）。
- 核心、語言與溝通：課程時間表每個系所資料裡的 `brief` 對照表，key 是 `<學期>_<課號>`，value 是 `{ "<代碼>": { brief_code, brief } }`。代碼以逗號分隔，例如 `A505,Z204`。判斷規則：
  - `Z100`–`Z104`：核心・基本素養
  - `Z105`–`Z108`：核心・領域課程
  - `Z2` 開頭：語言與溝通
  - 一門課可以同時屬於多個類別。
- 舊課程資料沒有代碼：課程類別篩選只剩必修、選修可用，並提示「重新更新課程資料後才能篩核心、語言與溝通」。

### 其他篩選（全部同時生效）

- **校區**（多選，沒選就不限）：課程任一時段的校區在選中的清單裡。
- **開課單位**（多選，沒選就不限）：`course.dep`。
- **學分**：最小值、最大值，空白代表不限。
- **關鍵字**：沿用 `lib/search.js` 的比對規則。
- **排除已有的課**：「正式選課」「預排」兩個勾選框，依課號排除。

### 排序

先分組（完全落在內、部分重疊），組內依第一個時段的星期、節次排，再依課號排。

## 2. 畫面與框選

### 版面

寬螢幕左右兩欄，窄視窗上下排列。

- 左欄：
  - 「帶入空堂：避開正式選課」「帶入空堂：避開正式選課＋預排」「全部清除」，以及「已選 N 格」。
  - 時段格子。
  - 篩選：比對方式、校區、類別、開課單位、學分、關鍵字、排除。
- 右欄：
  - 結果數與清單。
  - 部分重疊模式下分成兩組。

### 格子

- 7 欄（一到日）× 16 列（Y–D），列標題顯示節次代碼與開始時間，例如「3 10:10」。
- 每格兩種狀態：選取、未選。
- 已經有課的格子（正式選課＋預排＋自訂行程）用淡灰斜紋底並顯示課名縮寫，仍然可以框選。

### 框選規則（純函式 `src/lib/grid-select.js`）

- **拖曳**：起點格子決定模式。起點未選就是「選取」，起點已選就是「取消」。起點到目前格子構成矩形，矩形內全部套用這個模式。拖曳中即時預覽，放開才寫入。
- **點一格**（按下與放開在同一格）：切換那一格。
- **點星期標題**：如果那天全部已選就整天取消，否則整天選取。**點節次標題**：同樣規則套用到一週的那一節。
- 同時支援滑鼠與觸控板（Pointer Events）。拖曳時不會選到文字。

### 結果清單

- 每門課一張卡片：
  - 課號、課名（連到課程大綱）
  - 老師、時段（例如「五 34」）、教室、校區、學分、類別、開課單位
  - 部分重疊的課加一行「超出：…」
  - 右側是「加入」按鈕
- **滑過卡片**：格子上用藍框標出這門課在範圍內的時段，紅框標出超出的時段。離開就清掉。
- 最多顯示 200 門，超過時提示「共 N 門，只顯示前 200 門，請再縮小條件」。

### 加入預排

- 找一個已開啟的選課網分頁（`chrome.tabs.query({ url: 'https://cos.nycu.edu.tw/*' })`），透過 content script 送出。找不到或沒登入時，在按鈕旁提示「請先開啟並登入選課網」。
- 沿用採計方式邏輯（`lib/attribution.js` 的 `findAttributionOptions`、`needsChoice`、`preregParams`）：有兩種以上採計方式，或只在核心等其他選單找到時，先讓使用者選。
- 已在預排的課，卡片上標「已在預排」，不顯示「加入」。

### 記住狀態

`chrome.storage.local` key `planner`：`{ selection: string[], filters: {...} }`。每次變更都存，頁面打開時讀回。讀不到或格式不對就用預設值：沒有選取、完全落在內、其他不限。

## 3. 資料、檔案結構、測試

### 爬蟲

`src/lib/timetable.js` 的 `parseCosList` 多存 `brief: string[]`（該課的類別代碼，從系所資料的 `brief['<學期>_<課號>']` 的 key 拆開）。多系合開的課，各系資料裡的代碼合併去重。需要使用者重新「更新課程資料」才會有。

### 檔案

```
src/planner.html, planner.css, planner.js   選課規劃頁（找空堂）
src/planner/slot-grid.js                    框選格子（DOM 與 pointer 事件）
src/planner/results.js                      結果清單、滑過預覽、加入預排
src/lib/freeslots.js                        時段、空堂、比對、類別、篩選、排序
src/lib/grid-select.js                      框選規則
src/lib/timetable.js                        parseCosList 多存 brief
src/cos-tab.js                              找已開啟的選課網分頁並送訊息（從 src/register.js 抽出，兩頁共用）
src/popup.html / popup.js                   外殼右上加「規劃 ↗」
```

### 測試

單元測試：

- `freeslots.js`：
  - 課程時段與校區解析
  - 空堂計算（兩種依據、自訂行程、被隱藏的課）
  - 完全落在內／部分重疊（多時段、跨校區、沒有時間）
  - 類別代碼判斷
  - 每一種篩選與組合、排序、200 門上限
- `grid-select.js`：起點決定模式、矩形範圍（任意方向拖曳）、點一格切換、整天與整節切換。
- `timetable.js`：類別代碼解析、多系合開合併。

瀏覽器測試（假資料）：

- 帶入空堂的兩種依據
- 拖曳框選與取消、點標題切換整天或整節
- 兩種比對方式的分組與「超出」標示
- 每一種篩選
- 滑過卡片的格子預覽
- 加入預排（含採計選擇；沒有選課網分頁時的提示）
- 重新打開頁面後，選取與篩選都還在
- popup 的「規劃 ↗」會開啟這一頁
