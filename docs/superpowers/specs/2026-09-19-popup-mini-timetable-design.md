# Popup 改版：迷你課表與 tab 架構

日期：2026-09-19
狀態：設計已確認，待實作

## 目的

讓擴充功能在開學後仍然每天有用。主要情境：「我正在上課、快下課了，下一堂在哪？」使用者點開 popup，一眼看到課表和下一堂的教室，然後關掉。

原則：**popup 只放小工具等級的東西**。點開、看一眼或做一個小動作就關掉。大功能（例如之後的課程規劃）做成獨立的 Chrome 分頁，跟現在的「週課表」「選課」頁一樣，popup 頂多放一個開啟它的按鈕。

## 範圍

要做：

- popup 改成 tab 架構，目前兩個 tab：「加入預排」「課表」。
- 「課表」tab：迷你週課表、下一堂資訊、點格子看詳情、下方搜尋框可直接加入預排。
- 「加入預排」tab：現有 popup 的完整功能搬進來，行為不變。
- 記住上次停在哪個 tab。

不做：

- 課程規劃，或任何大功能。
- Google 日曆整合，只在資料模型上預留（見「之後的擴充」）。
- 校曆、學期起訖、放假日。任何日期都照週課表顯示。

## 使用者確認過的決定

| 項目 | 決定 |
|---|---|
| 首頁形狀 | 迷你週課表（不是「今天清單」或只有下一堂） |
| 格子內容 | 課名縮寫＋教室 |
| 節次範圍 | 只列這週有課的範圍，中間空堂照列；週末沒課就不列 |
| 課程來源 | 正式選課＋自訂行程（與完整課表頁的正式課表相同） |
| tab 順序 | 1. 加入預排　2. 課表；之後可能調整或新增 |
| 預設 tab | 記住上次停的 tab |
| 課表 tab 的搜尋框 | 放在課表下方，打字後結果往下展開，可直接加入預排 |
| 點格子 | 一律先展開詳情，連結放在詳情裡 |
| tab 架構 | 方案 A：tab 登記表＋各 tab 獨立模組 |

## 1. 迷你課表的計算（純函式，`src/lib/`）

### 資料來源：`scheduleItems(schedule, sources)`

目前組合課表項目的 `syncedItems` / `currentItems` 只在 `src/schedule.js`（課表頁）裡。搬到 `src/lib/schedule.js`，改名為 `scheduleItems`，課表頁和 popup 共用。

- 輸入：storage 裡的 `schedule`（`sources`、`manual`、`overrides`），以及要用的來源清單，例如 `['registered']` 或 `['registered', 'preregist']`。
- 輸出：課表項目陣列。同步進來的課和自訂行程合併，套用覆寫（隱藏、顏色、連結）。同一課號只留一筆，排在前面的來源優先。
- popup 固定用 `['registered']`，加上自訂行程。
- 這是所有來源唯一的匯入點。之後加 Google 日曆，就是在這裡多一種來源。

### 排版：`buildWeek` 加 `mergeBlocks`

- 沿用現有 `buildWeek(items)`：只列有行程的節次範圍，週末沒行程不列。
- 新增 `mergeBlocks(week)`：同一天、同一個項目的連續節次合併成一個區塊，記錄起始列和跨幾列。例如週三 3–4 節的線性代數，只顯示一次課名與教室，高度佔兩列。
- 同一格有兩個以上項目（衝堂）時，區塊並排並標示衝堂，不互相覆蓋。

### 現在與下一堂：`locateNow(layout, now)`，放在 `src/lib/now.js`

`layout` 是 `mergeBlocks` 的結果，包括列出的各列和各列的時間，以及每個區塊的星期、起始列、跨列數、開始和結束時間。`mergeBlocks` 會用節次對照表（`PERIODS`）把每個區塊換算成開始、結束的鐘點（分鐘數）。

`locateNow` 只用鐘點計算，不看節次代碼，好讓之後任意時間的活動（例如 19:15–20:40）也能放進來。

回傳：

- `current`：現在正在進行的區塊，沒有就是 null。
- `next`：下一個區塊。先找今天稍後的；今天沒有就找之後最近一天的第一個，會繞回下週。整週都沒有就是 null。
- `minutesUntilNext`：距離 `next` 開始幾分鐘（只算今天的；跨日時給日期文字，例如「週一 08:00」）。
- `nowLine`：現在時間線的位置（第幾列、該列內的比例）。落在課間休息時，線畫在兩列之間。時間在列出的範圍之外（例如清晨、深夜）時為 null，不畫。
- `today`：今天是星期幾（1–7），用來加深今天那一欄。

必須有測試的邊界：上課中、課間休息、午休（N 節）、今天已沒課、週六日、深夜、這週完全沒課、登記中的課、衝堂、自訂時間的行程。

### 特殊標示

- 登記中（還沒分發）的課：虛線外框，詳情寫「登記中・第 N 志願」。
- 衝堂：見上面的 `mergeBlocks`。

## 2. 畫面與互動

### 外殼（所有 tab 共用）

- 頂端 tab 列，樣式像 Chrome 分頁：「加入預排」「課表」。
- tab 列右側放小按鈕：「選課 ↗」開選課頁，「⋯」放不常用的功能，例如更新課程資料、開啟完整週課表。
- 選課網連線狀態（未登入、系統暫停中等）只在需要時顯示一行，平常不佔空間。
- 寬度約 420px；高度隨內容，最高 600px（Chrome popup 上限）。
- 深色模式跟著系統。

### 課表 tab

由上而下：

1. **迷你週課表**
   - 欄是星期，列是節次；列標題顯示節次代碼。
   - 每格顯示課名（約 4 字，太長用「…」）和教室。
   - 今天那一欄底色加深，一條細紅線標出現在時間，下一堂的格子加外框。
   - 課表位置永遠固定，不因搜尋或詳情而移動。
2. **下一堂列**
   - 一行文字，例如「下一堂 10:10（8 分鐘後）・線性代數・SC201」。
   - 正在上課時改成「上課中：線性代數・SC201，11:00 下課；下一堂 …」。
   - 這一行是整個 popup 最重要的資訊。
3. **詳情區**
   - 點格子後在這裡展開：完整課名、時間、教室、老師、登記狀態，以及「開啟連結」（使用者設的，例如 E3）「課程大綱」「設定連結」。
   - 點同一格收起，點別格就切換。
   - 「設定連結」開完整課表頁去設定，popup 裡不做編輯表單。
4. **搜尋框**
   - 使用共用的「找課元件」。打字後結果往下展開，每筆可直接「加入」，含採計方式選擇。清空就收起。

沒有正式選課時，課表區顯示「還沒有正式選課」，附「看預排課表 ↗」和「從選課網同步」。

### 加入預排 tab

現有 popup 的完整功能：搜尋與加入（含採計選擇）、查人數、批次貼課號、更新課程資料與進度、選課網狀態、學期不符警告。行為不變，只重新排版。

### 記住 tab

切換 tab 時把 tab id 存到 `chrome.storage.local`（key：`popupTab`），下次開 popup 直接顯示。存的 id 已不在 tab 清單時，退回第一個 tab。讀取失敗時也退回第一個。

## 3. 資料更新、檔案結構、測試

### 正式選課資料的更新

- popup 打開時，先用 storage 裡上次的資料立即畫出課表，不等網路。
- 如果有已開啟、已登入的選課網分頁，就在背景讀一次（content script 既有的 `courses` 訊息），寫回 `schedule.sources.registered`。資料有變就重畫，並在課表右下角小字顯示「更新於 HH:MM」。
- 沒有選課網分頁、未登入或讀取失敗時，不提示也不清空，繼續用上次的資料。

### 檔案結構

```
src/popup.html, src/popup.css     外殼：tab 列、右側按鈕、狀態列
src/popup.js                      外殼邏輯：tab 清單、切換、記住 tab、共用工具
src/popup/tabs/add.js             加入預排 tab（現有 popup 功能搬過來）
src/popup/tabs/schedule.js        課表 tab
src/popup/course-search.js        搜尋＋加入元件（兩個 tab 共用）
src/lib/schedule.js               新增 scheduleItems、mergeBlocks
src/lib/now.js                    locateNow
src/lib/tabs.js                   tab 清單與「記住的 tab」的選擇規則（純函式）
```

tab 清單：

```js
[
  { id: 'add', label: '加入預排', module: addTab },
  { id: 'schedule', label: '課表', module: scheduleTab },
]
```

每個 tab 模組提供：

- `mount(container, ctx)`：第一次顯示時建立畫面。`ctx` 是外殼提供的共用工具，例如選課網分頁、送訊息、顯示狀態。
- `show()`：每次切換到這個 tab 時呼叫，用來重新整理。

要調整順序或新增小工具 tab，只改這個清單並加一個模組檔。

目前 730 行的 `popup.js` 依責任拆開：外殼、加入預排 tab、找課元件。課表頁 `src/schedule.js` 改用 `lib/schedule.js` 的 `scheduleItems`，行為不變。

### 測試

單元測試（`node --test`）：

- `scheduleItems`：來源合併、優先順序、覆寫、自訂行程。
- `mergeBlocks`：連續節次合併、衝堂。
- `locateNow`：上面列出的所有邊界。
- `tabs.js`：清單順序、記住的 tab 不存在時退回第一個。

瀏覽器測試（Playwright＋假選課網，headless）：

- 課表 tab：固定時間下檢查時間線位置、下一堂列文字、今天欄位、點格子展開與收起詳情。
- 沒有正式選課時的空狀態。
- 課表 tab 的搜尋框加入預排（含採計選擇）。
- 切換 tab、關掉 popup 再開，回到同一個 tab。
- 背景更新：選課網回傳不同的正式選課時，課表會重畫。
- 現有 popup 測試（加入、批次、採計選擇、查人數、暫停訊息、學期警告）改到「加入預排」tab 後照樣通過。

截圖：淺色、深色各一張給使用者確認。

## 之後的擴充（這次不做）

- **Google 日曆等外部行事曆**：在 `scheduleItems` 多一種來源。`locateNow` 已用鐘點計算，任意時間的活動可以直接放進來。
- **更多小工具 tab**：改 tab 清單＋加模組。
- **課程規劃等大功能**：獨立 Chrome 分頁，popup 最多在右上放一個入口按鈕。
