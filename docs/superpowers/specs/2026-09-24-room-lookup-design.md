# 教室查詢：一間教室現在上什麼課、整棟樓哪裡沒有排課

日期：2026-09-24。接在 0.11.0（分支 `fix-reg-rules`，commit `e1b9654`）之後。

## 目的

讓學生快速：
- **找旁聽**：選一棟或幾棟樓，看現在哪些教室正在上課、上什麼課、誰教、上到幾點。
- **找自習的地方**：看哪些教室這個時段沒有排課、可以待到幾點。
- **查單一教室**：輸入教室代碼（例如 `ED219`），看它現在的狀態和一週課表。

## 使用者已決定

| 項目 | 決定 |
|---|---|
| 放在哪裡 | 擴充功能裡的新頁面（只有電腦能用，不做手機版） |
| 時間 | 預設「現在」，可以改成指定星期幾與時間 |
| 範圍 | 可以選一棟或多棟樓，再選樓層 |
| 資料來源 | 做法 A：用擴充功能已下載的課程資料＋官方大樓代碼表（開頁時抓、存快取） |

## 實測資料（2026-09-24，115 學年第 1 學期，選課網全掃描 3,719 門課）

- **官方大樓代碼表**：`POST https://timetable.nycu.edu.tw/?r=main/get_classroom_code`，不需要登入，回傳 7 個校區共 57 棟：
  ```json
  { "Guang-Fu": { "cname": "新竹光復校區", "ename": "…", "campus_code": "[GF]", "build_num": 26,
                  "map": "https://www.nycu.edu.tw/about/campus-maps/",
                  "code": { "ED": { "cname": "工程四館", "ename": "Engineering Building IV" }, … } }, … }
  ```
  課程時間表自己的「星期／時間／教室代碼對照表」就是用這支 API（`public/js/timetable.js` 的 `get_classroom_code`）。
- **教室代碼**：課程時間字串 `M34-ED219[GF]` 的 `ED219`。全校排了課的教室有 440 間，51 種大樓前綴。
  - 用「最長的已知大樓代碼當前綴」比對，**94%** 的教室時段對得上（例如 `YED109` → `YE` 實驗大樓，`AB` 綜合一館地下室 ≠ `A` 綜合一館）。
  - 對不上的：`PE`（體育，109 個時段，沒有教室號碼）、`PhE`（39）、北門 `TB` 開頭（33）、`HH201`（1）。
  - 號碼形式：字母＋3 位數字最多（2,622），2 位數 46、4 位數 5；另有 `CS-PC2`、`M-b09`（地下室）、`YB636-1`、`HB212-3R` 這類。
  - 一個時段可能列多間教室，`parseCosTime` 會用「、」串起來。
- **沒有教室的課**：**21%** 的上課時數沒有填教室（只寫 `M678-`），另有 221 門課完全沒有上課時間。考試、演講、教室借用、補課也都不在課程資料裡。

### 控制項
- **校區**：單選，預設光復（GF）；記住上次的選擇。只列有排課教室的校區。
- **大樓**：多選。列出這個校區所有有排課的大樓，每棟一個切換按鈕（官方名稱＋代碼＋有排課的教室數）；對不上官方名稱的只顯示代碼，排在最後。沒選任何大樓時，列表區提示「先選一棟或幾棟大樓」，不列出全校。換校區時清空已選的大樓與樓層。
- **樓層**：依已選大樓出現過的樓層產生按鈕，可多選；都不選等於全部。
- **時間**：
  - 「現在」：用電腦目前的星期與時間，每分鐘自動重算。
  - 「指定」：星期（一到日）＋時間（HH:MM）。
- **顯示**：全部／只看沒排課／只看上課中。
- **找教室**：輸入代碼（不分大小寫、可只打開頭，例如 `ed2`），列出符合的教室供點選；按 Enter 不做任何事（避免注音選字的 Enter 誤觸，見 0.11.0 系所搜尋的教訓），要用點的。
- 校區、大樓、樓層、顯示、時間模式都存在 storage 的 `rooms`，下次打開還在。

### 列表（左欄）
依「大樓 → 樓層 → 教室代碼」排序分組。每間教室一列，顯示在選定時間的狀態：
- **上課中**：課名、老師、「到 HH:MM」。同一時間同一教室有多門課（合開或衝堂）全部列出。
- **沒有排課**：「到 HH:MM 前沒有排課」或「今天之後沒有排課」。
- 整列是一個按鈕，點了 → 右欄顯示這間教室的狀態與一週課表。課程大綱的連結放在右欄（按鈕裡不能再放連結）。

### 單一教室週課表（右欄）
- 標題：教室代碼、大樓名稱、樓層；下面一行是選定時間的狀態，上課中的課名連到課程大綱。
- 重用 `src/planner/timetable.js` 的 `createTimetable`（`stackWeek` 排版）。每門課轉成 `source: 'manual'` 的課表項目（顏色固定一色），只放這間教室的時段。
- 選定的時間所在的那一格用 `preview([key])` 標亮。
- 點課表上的課 → 開課程大綱（`courseOutlineUrl`）。
- 版面與當期選課相同：寬視窗左右兩欄各自捲動；窄視窗（< 880px）上下排。左右寬度固定（不做可拖曳分隔線）。

### 誠實的說明
- 全頁不出現「空教室」，一律說「沒有排課」。
- 固定顯示說明：「只根據課程資料：考試、演講、教室借用不在內，『沒有排課』不代表一定沒人。」
- 顯示「這個時段全校另有 N 門課沒有填教室」：N = 在選定時間正在上課、但該時段沒有教室的課程數。沒有教室的時段多半也沒有校區，所以只能算全校。
- 沒有課程資料時：提示先到「當期選課」按「更新課程資料」。

## 計算規則（`src/lib/rooms.js`，全部是純函式）

### 教室代碼 → 大樓、樓層
`parseRoom(code, campus, buildings)`：
- `buildings`：`{ [campus]: { [buildingCode]: { cname, ename } } }`（由官方表整理，見下）。
- 大樓：該校區的大樓代碼中，**最長**且是教室代碼開頭的那個（區分大小寫，官方代碼有 `Lib` 這種）。找不到時，大樓代碼取教室代碼開頭的英文字母，名稱就用代碼本身（`未對上官方名稱`）。
- 樓層：大樓代碼後面剩下的部分——
  - 以數字開頭，或一個英文字母（側翼）再接數字：那個數字（`ED219` → `2`；`YED109` 是 `YE` 後面接 `D109` → `1`）；`0` 開頭的另成一組「0 字頭」（還沒確認是地下室還是一樓）。
  - `-b` 或 `b` 開頭再接數字（不分大小寫，`M-b09`、`Lib-B1`）：地下室 `B`，這條先判斷。
  - 其他（`PE`、`CS-PC2` 的 `-PC2`）：`其他`。
- 回傳 `{ code, campus, building, buildingName, floor, known }`，`known` 表示大樓有對上官方表。

### 教室索引
`buildRoomIndex(courses, buildings)`：
- 對每門課 `parseCosTime(course.time)` 的每個時段，把 `room` 用「、」拆開，每間教室記一筆 `{ day, period, course }`。
- 回傳 `{ rooms: Map<房間 key, { …parseRoom 結果, slots: [{ day, period, course }] }>, noRoom: [{ day, period, course }] }`。房間 key = `${campus}:${code}`（不同校區可能有同名教室）。

### 上課區間
同一門課在同一天、同一間教室、節次在 `PERIODS` 裡**相鄰**的，合成一段；區間 = 第一節開始到最後一節結束。
例：`W34` = 10:10–12:00（中間的下課也算在上課中）。

### 某個時間點的狀態
`roomStatus(room, day, minute)`：
- `busy`：有區間包含 `minute`（`start ≤ minute < end`）。回傳 `{ state: 'busy', courses, until }`，`until` = 這些區間最晚的結束時間。
- `free`：回傳 `{ state: 'free', until }`，`until` = 當天在 `minute` 之後最早開始的區間開始時間；沒有就是 `null`（今天之後沒有排課）。
`noRoomCount(index, day, minute)`：在該時間正在上課、但時段沒有教室的**不同課程**數。

## 官方大樓表的取得與快取（`src/lib/buildings.js`）

- `normalizeBuildings(json)`：官方回應 → `{ campuses: [{ code: 'GF', cname, ename, map }], buildings: { GF: { ED: { cname, ename } } } }`。`campus_code` 的 `[GF]` 去掉括號。
- `loadBuildings({ fetchImpl, storage, now })`：
  - storage 的 `roomBuildings = { fetchedAt, data }` 存在且未滿 30 天 → 直接用。
  - 否則向官方 API 抓，成功就寫回快取；失敗就用舊快取；連舊快取都沒有 → 回傳 `null`，頁面照常運作，大樓名稱改顯示代碼。
- 擴充功能已經有 `https://timetable.nycu.edu.tw/*` 的 host 權限，不需要新增權限。

## 不做

- 節假日、隔週上課、只上前八週（課程資料沒有這些資訊）。
- 教室借用系統的資料（要另外登入）。
- 手機版。
- 從課程資料以外的來源補沒有填教室的課。
