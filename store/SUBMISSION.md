# Chrome Web Store 上架步驟

版本：0.2.0，上傳檔案 `dist/nycucourse-extension-0.2.0.zip`（`scripts/pack.sh` 產生）。

## 需要你本人做的事

1. 註冊開發者帳號：<https://chrome.google.com/webstore/devconsole>，用 Google 帳號登入，同意開發者協議，付一次性註冊費。
2. 把隱私權政策放到公開網址（見下方「隱私權政策網址」）。
3. 依下面欄位填表，按「提交審查」。

## 1. 套件

- 「新增項目」→ 上傳 zip。
- 上傳後後台會讀出名稱、版本、圖示，確認是 `NYCU 預排課程匯入`、`0.2.0`。

## 2. 商品詳細資料（Store listing）

| 欄位 | 內容 |
|---|---|
| 說明 | 複製 `store/description.md` 的「詳細說明」段落 |
| 類別 | 生產力（Productivity）→ 若有「教育」子類可選教育 |
| 語言 | 中文（繁體） |
| 商店圖示 | `icons/icon128.png` |
| 螢幕截圖 | `store/images/screenshot-1.png`、`screenshot-2.png`、`screenshot-3.png`（1280×800） |
| 小型宣傳圖塊 | `store/images/promo-small-440x280.png` |
| 官方網址 | 留空，或填 repo 網址 |
| 支援網址 | repo 的 issues 頁（放上 GitHub 後） |

## 3. 隱私權實務（Privacy practices）

**單一用途說明**

> 協助使用者搜尋陽明交大課程並加入選課系統的預排課程。

**權限理由**

| 權限 | 理由 |
|---|---|
| activeTab | 判斷目前分頁是否為陽明交大選課系統（cos.nycu.edu.tw），並與該分頁的內容腳本溝通以加入預排課程。 |
| storage | 將使用者手動下載的公開課程資料存在本機，供離線搜尋。不儲存任何個人資料。 |
| 主機權限 cos.nycu.edu.tw | 在選課系統頁面注入內容腳本，以使用者目前的登入狀態呼叫該網站自身的預排課程 API。 |
| 主機權限 timetable.nycu.edu.tw | 下載學校公開的課程時間表資料，建立搜尋用的課程清單。 |

**是否使用遠端程式碼**：否。所有 JavaScript 都包含在套件內。

**資料使用揭露**：以下類別全部**不勾選**。

- 個人識別資訊、健康、財務、驗證資訊、個人通訊、位置、網頁瀏覽記錄、使用者活動、網站內容

說明：擴充功能會在選課系統頁面內使用既有的登入權杖發出同網站請求，但權杖不會被讀出、儲存或傳送到開發者或第三方，因此不屬於「收集」。若審查人員認為屬於「驗證資訊」，改勾選它，並聲明「不出售、不用於與單一用途無關的目的、不用於信用評估」。

**三項聲明全部勾選**

- 我不會出售或轉移使用者資料給第三方（核准用途除外）
- 我不會將使用者資料用於與商品單一用途無關的目的
- 我不會將使用者資料用於判斷信用或放款

**隱私權政策網址**

`store/privacy.md` 需要一個公開網址。最簡單的做法：

1. 把 repo 推到 GitHub（公開）。
2. 網址填 `https://github.com/<帳號>/nycucourse-extension/blob/master/store/privacy.md`。

## 4. 發布設定（Distribution）

- 顯示設定：**公開**。選課快結束，想先小範圍收回饋可以選「不公開（Unlisted）」，只有拿到連結的人能安裝。
- 地區：全部地區。
- 價格：免費。

## 5. 審查注意

- 新帳號、新項目、帶主機權限，審查通常數天到一兩週，選課結束前不一定能過。
- 常見退件原因：權限理由太籠統、隱私權政策網址打不開、截圖與功能不符。以上欄位已針對這三點準備。
- 若被退件，把退件信內容貼給 Claude 修改。

## 之後更新版本

1. 改 `manifest.json` 的 `version`。
2. `npm test`，`scripts/pack.sh`。
3. 後台該項目 →「套件」→ 上傳新版 zip → 提交審查。
