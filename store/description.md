# 商店說明

## 名稱
NYCU 預排課程匯入

## 簡短說明（取自 manifest，132 字以內）
搜尋與規劃陽明交大課程：找空堂、加入預排與正式選課、查空教室，並提供課表與每日自動登記。

## 詳細說明
陽明交通大學選課系統要先選學院、系所才找得到課，加退選期間每天還要重新登記。這個擴充功能把找課、排課、選課、看課表、找教室放在一起。

【點開就看到課表】
- 工具列圖示點開就是這週的課表：今天那一欄加深，紅線是現在時間。
- 點一堂課看教室、老師，開啟你設定的連結（例如 E3）或課程大綱。
- 上方按鈕直接開啟「當期選課」「教室查詢」「編輯課表」。

【當期選課：找空堂、找課】
- 左邊是搜尋結果，右邊是「課表預覽」「篩選設定」「自動登記」三個分頁；中間的分隔線可以拖曳調整寬度。
- 時段可以一鍵「全選」「空堂」（扣掉已選上的課）「清除」，也能在格子上按住拖曳框選。
- 可以篩選完全落在時段內或部分重疊的課，也能篩校區、類別（必修、選修、核心、語言與溝通）、系所（可複選、可搜尋）與關鍵字。支援片段比對，例如輸入「線代」可以找到「線性代數」。
- 每門課標出目前狀態：已選上、已登記（等分發）、在預排，判斷方式和選課網相同。
- 第一次使用時先按「下載課程資料」，下載學校公開的課程時間表；之後每個頁面上都可以「更新課程資料」。

【查詢、加選、登記、變更採計】
- 列出每種採計方式（例如選修或核心）能不能選、人數與衝堂原因。
- 和選課網的按鈕一樣：不限人數的課直接加選，有人數上限的課登記等分發，志願序課程可以選第幾志願。送出前一定會再確認一次。
- 已經在預排的課可以改採計方式；改不成功時會還原原本的預排。
- 選課系統暫停或選課結束時，會直接顯示學校公告的說明。

【教室查詢】
- 選校區、大樓、樓層，看每間教室現在在上什麼課，或空到幾點；也可以指定星期與時間。
- 點一間教室看它一週的課表，方便找旁聽的課，或找沒排課的教室自習。
- 資料只來自課程時間表：考試、演講、借用教室不在內。

【每日自動登記】（選用，預設關閉）
- 加退選期間每天開放登記，分發後要重新登記。你可以指定課程、志願和每天的時間，擴充功能會在那個時間幫你登記。
- 已登記或已選上的課不會重送；選課系統暫停、沒登入或讀不到資料時不會送出，並留下紀錄。

【編輯課表】
- 加入外校課程或自己的固定行程，設定課程連結與顏色。開學後也天天用得到。

使用方式：先在 Chrome 登入選課系統。所有選課操作都在選課系統網站內、用你自己的登入狀態進行。擴充功能不會讀取或保存你的密碼，也不會把資料傳給開發者或第三方。不提供退選。

本擴充功能非學校官方工具。原始碼公開於 GitHub。

## 類別
生產力工具（Productivity）；如有教育（Education）可選教育

## 單一用途說明（審核用）
協助陽明交大學生選課：搜尋與規劃課程、加入預排與正式選課，並以課表檢視已選課程。

## 權限說明（審核用）
- storage：把公開課程資料、使用者自己的課表、當期選課的時段與篩選條件、自動登記設定存在本機。
- alarms：使用者開啟「每日自動登記」時，在使用者設定的時間執行登記。未開啟時不建立任何排程。
- host_permissions cos.nycu.edu.tw：在選課系統頁面內注入腳本，以使用者目前的登入狀態呼叫該站自身的預排、選課 API。
- host_permissions timetable.nycu.edu.tw：下載學校公開的課程時間表與教室代碼（大樓名稱）資料。
