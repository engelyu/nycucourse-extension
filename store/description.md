# 商店說明

## 名稱
NYCU 預排課程匯入

## 簡短說明（取自 manifest，132 字以內）
搜尋陽明交大課程，一鍵加入預排或正式選課，並提供我的課表與每日自動登記。

## 詳細說明
陽明交通大學選課系統要先選學院、系所才找得到課，加退選期間每天還要重新登記。這個擴充功能把找課、排課、選課放在一起。

【搜尋與預排】
- 用課名、老師或課號搜尋全校課程，支援片段比對，例如輸入「線代」可以找到「線性代數」。
- 搜尋結果顯示人數上限，可即時查目前登記人數，並附課程綱要連結。
- 按「加入」放進選課系統的預排課程；也能一次貼上多個課號批次加入。
- 課程資料按「更新課程資料」從學校課程時間表下載，存在自己的電腦。

【我的課表】
- 用週課表顯示預排課程或正式選上的課，兩者可以切換，離線也能看。
- 可以加入外校課程或自己的固定行程，並替每堂課設定連結（例如 E3）與顏色。

【正式選課】
- 從預排課程直接加選；通識、體育等志願序課程可以選擇第幾志願，也能改志願。
- 清楚區分「已登記」（等分發）和「已選上」。
- 選課系統暫停時（例如分發時段），會直接顯示學校公告的暫停時間。

【每日自動登記】（選用，預設關閉）
- 加退選期間每天中午開放登記，分發後要重新登記。你可以指定課程、志願和每天的時間（例如 13:00），擴充功能會在那個時間幫你登記。
- 已登記或已選上的課不會重送；選課系統暫停或登入過期時不會送出，並留下紀錄。
- 執行時電腦和 Chrome 要開著，選課網要保持登入。

使用方式：先在 Chrome 登入選課系統，所有操作都用你自己的登入狀態在選課系統網站內進行。擴充功能不會讀取或保存你的密碼，也不會把資料傳給開發者或第三方。

本擴充功能非學校官方工具。原始碼公開於 GitHub。

## 類別
生產力工具

## 單一用途說明（審核用）
協助陽明交大學生選課：搜尋課程、加入預排或正式選課，並以課表檢視已選課程。

## 權限說明（審核用）
- storage：把公開課程資料、使用者自己的課表與自動登記設定存在本機。
- alarms：使用者開啟「每日自動登記」時，在使用者設定的時間執行登記。未開啟時不建立任何排程。
- host_permissions cos.nycu.edu.tw：在選課系統頁面內注入腳本，以使用者目前的登入狀態呼叫該站自身的預排、選課 API。
- host_permissions timetable.nycu.edu.tw：下載學校公開的課程時間表資料。
