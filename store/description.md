# 商店說明

## 名稱
NYCU 預排課程匯入

## 簡短說明（取自 manifest，132 字以內）
搜尋與規劃陽明交大課程：找空堂、加入預排與正式選課，並提供課表與每日自動登記。

## 詳細說明
陽明交通大學選課系統要先選學院、系所才找得到課，加退選期間每天還要重新登記。這個擴充功能把找課、排課、選課、看課表放在一起。

【點開就看到課表】
- 工具列圖示點開就是這週的課表：今天那一欄加深，紅線是現在時間。
- 點一堂課看教室、老師，開啟你設定的連結（例如 E3）或課程大綱。
- 可以加入外校課程或自己的固定行程。開學後也天天用得到。

【用關鍵字找課，加入預排】
- 用課名、老師或課號搜尋全校課程，支援片段比對，例如輸入「線代」可以找到「線性代數」。
- 同一門課可能算選修或核心課程，加入預排時就讓你選好採計方式。
- 可以即時查目前的登記人數，也能一次貼上多個課號批次加入。

【選課規劃：找空堂課程】
- 在一週的時段格子上按住拖曳，框出想上課的時段；或一鍵帶入所有空堂。
- 可以篩選完全落在時段內或部分重疊的課，也能篩校區、類別（必修、選修、核心、語言與溝通）、系所（可複選、可搜尋）與關鍵字。
- 滑過一門課，格子上就會標出它的上課時間。
- 每門課標出目前狀態：已選上、登記中、在預排。

【查詢、加選、登記】
- 列出每種採計方式能不能選、人數與衝堂原因。
- 可以直接加選，志願序課程可以選第幾志願。送出前一定會再確認一次。
- 選課系統暫停時（例如分發時段），會直接顯示學校公告的暫停時間。

【每日自動登記】（選用，預設關閉）
- 加退選期間每天中午開放登記，分發後要重新登記。你可以指定課程、志願和每天的時間，擴充功能會在那個時間幫你登記。
- 已登記或已選上的課不會重送；選課系統暫停、沒登入或讀不到資料時不會送出，並留下紀錄。

使用方式：先在 Chrome 登入選課系統。所有選課操作都在選課系統網站內、用你自己的登入狀態進行。擴充功能不會讀取或保存你的密碼，也不會把資料傳給開發者或第三方。不提供退選。

本擴充功能非學校官方工具。原始碼公開於 GitHub。

## 類別
生產力工具（Productivity）；如有教育（Education）可選教育

## 單一用途說明（審核用）
協助陽明交大學生選課：搜尋與規劃課程、加入預排與正式選課，並以課表檢視已選課程。

## 權限說明（審核用）
- storage：把公開課程資料、使用者自己的課表、選課規劃的時段與篩選條件、自動登記設定存在本機。
- alarms：使用者開啟「每日自動登記」時，在使用者設定的時間執行登記。未開啟時不建立任何排程。
- host_permissions cos.nycu.edu.tw：在選課系統頁面內注入腳本，以使用者目前的登入狀態呼叫該站自身的預排、選課 API。
- host_permissions timetable.nycu.edu.tw：下載學校公開的課程時間表資料。
