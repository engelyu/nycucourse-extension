# 商店說明

## 名稱
NYCU 預排課程匯入

## 簡短說明（132 字以內）
搜尋課名、老師或課號，一鍵加入陽明交大選課系統的預排課程。

## 詳細說明
陽明交通大學選課系統的預排頁面必須先選好學院、系所才能找到課。這個擴充功能讓你直接用關鍵字搜尋全校課程，按「加入」就放進預排課程區。

功能：
- 搜尋課名、老師名字或課號，支援片段與模糊比對，例如輸入「線代」可找到「線性代數」。
- 按一下「更新課程資料」就會從學校課程時間表下載整學期課程，存在本機，之後搜尋不需要網路。
- 也能一次貼上多個課號批次加入，接受「1151_516702」這種帶學期前綴的格式。
- 加入結果會標示成功、已在預排或失敗原因。

注意：預排課程不是正式選課。正式選課請依學校公告在選課系統操作。

本擴充功能非學校官方工具。

## 類別
生產力工具

## 單一用途說明（審核用）
協助使用者搜尋陽明交大課程並加入選課系統的預排課程。

## 權限說明（審核用）
- storage：把公開課程資料存在本機供搜尋。
- host_permissions cos.nycu.edu.tw：在選課系統頁面內注入腳本，呼叫該站自身的預排 API。
- host_permissions timetable.nycu.edu.tw：下載學校公開的課程時間表資料。
